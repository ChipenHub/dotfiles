# Deslop Prose

## Overview

Strip decorative scaffolding while preserving facts, links, code blocks, numbers, and the author's real voice.

## Workflow

1. Read the full draft before rewriting.
2. Identify the audience, formality, concrete facts, author voice clues, and slop scaffolding.
3. Inventory slop patterns before editing if the task is substantial.
4. Rewrite section by section.
5. Validate that no concrete facts disappeared and no AI register remains.

## Rules

- Delete decorative emoji, overused bold, filler dividers, and quote blocks that restate nearby prose.
- Replace marketing language with concrete claims.
- Drop forced numbered groupings unless the grouping is real.
- Use prose by default. Tables and bullets must earn their space.
- Do not add a closing summary unless the original had one or the user asks for one.
- Preserve blunt opinions when the source is blunt; do not sanitize critique.
- Ask for a reference sample if matching a personal voice matters and the input has no voice clues.

## Pattern Catalog

Read `references/slop-patterns.md` when the piece is long, Chinese-heavy, or visibly AI-written.

## Validation

After rewriting, read only the result. If it still smells like an LLM, run another pass before delivering.
