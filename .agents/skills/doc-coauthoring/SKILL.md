# Doc Coauthoring

## Overview

Guide a substantial document through context gathering, section drafting, and cold-reader testing.

## Stage 1: Context

Ask for:

- Document type.
- Primary audience.
- Desired reader action or decision.
- Required template or format.
- Constraints, background, alternatives, timelines, and stakeholder concerns.

Encourage an unstructured information dump. Ask clarifying questions after enough raw context exists.

## Stage 2: Structure And Draft

1. Propose 3-5 sections if no template exists.
2. Start with the highest-uncertainty section, often proposal or technical approach.
3. For each section, ask focused questions, brainstorm candidate points, let the user curate, then draft.
4. Edit surgically instead of reprinting the whole document.
5. Re-read the full document near completion for flow, redundancy, contradictions, and filler.

## Stage 3: Reader Testing

Test as a reader who lacks the conversation context:

- What questions would this reader ask?
- What assumptions are unstated?
- Which terms, references, or diagrams need more context?
- Does the summary match the body?
- Does every section support the desired reader action?

If the task is small, skip the full workflow and draft directly.
