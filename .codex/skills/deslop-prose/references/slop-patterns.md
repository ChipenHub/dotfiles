# Slop Patterns

## Surface Slop

- Emoji used as decoration in headings, bullets, or table cells.
- Bold around every important-looking noun phrase.
- Marketing hype: revolutionary, ultimate, game-changing, deep dive, cutting edge, supercharge, unleash.
- Chinese hype: 重磅, 革命性, 终极, 杀手级, 降维打击, 硬核, 封神, 史诗级.
- Empty calls to action: get started today, suggest saving this, stay tuned.
- Sanitized critique that removes the author's real opinion.
- Decorative scare quotes around ordinary metaphors.
- Redundant bilingual glosses after established terms.

## Structural Slop

- Forced "three key points" or "four advantages" framing.
- Two-row tables where prose is clearer.
- Every section sharing the same shape.
- Summary paragraph that repeats the opener.
- Horizontal rules between every section.
- Quote blocks that paraphrase nearby text.
- "In other words" followed by an empty restatement.
- "Actually / the essence is" repeated as a summary crutch.

## Chinese-Specific Signals

- 本质是 / 归根结底 / 说白了 as repeated openers.
- 这反而 / 反倒 / 倒是 used to manufacture a twist.
- 关键在于 tacked onto the end without adding a new constraint.
- 要么 X, 要么 Y, 要么 Z when the choices are not truly exclusive.
- Noisy single-character verbs where the natural two-character form is better.
- Goal-first sentences ending in 就行 / 就够了 / 就有了.
- Translationese such as 给定 X 的情况下, 让我们, 值得一提的是, 所谓的 when not used ironically.

## Rewrite Policy

Keep facts, numbers, names, code, links, and citations. Delete scaffolding. If deletion would remove a real claim, rewrite it plainly instead of dropping it.
